## 🚀 Featured Projects

### 🛡️ international-iam-platform

A modern Identity and Access Management platform built with Java 21 and Spring Boot.

Current features:

- Multi-tenant domain model
- User / Role / Permission / Client management
- OAuth2 Authorization Server
- OIDC and JWT support
- Scope-based RBAC authorization
- Audit logging
- TOTP MFA
- MFA secret encryption
- SCIM 2.0 foundation

> Goal: build a portfolio-level IAM system with international engineering standards.

[View Repository](https://github.com/doubletree0657/international-iam-platform)
